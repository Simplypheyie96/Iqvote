# Improvements

Drop improvement specs and design instructions for IQ Vote in this folder, one
file per topic.

These are **inputs** — things to be built. That's what separates them from the
rest of `docs/`, which describes how the app works today. When something here
ships, fold the durable parts into the relevant doc (`architecture.md`,
`voting-rules.md`, and so on) and delete the spec, so this folder stays a
to-do list rather than becoming another pile of history.
